# 市政井盖全生命周期管控大屏（前端）

天信城市生命线管网 AI 智慧平台 · 市政井盖全生命周期管控子模块可视化前端。

- 技术栈：Vue 3 + TypeScript + Vite 4 + Element Plus + ECharts 5 + Axios
- 对接后端：`manhole_cover_control`（FastAPI，默认 `http://localhost:8003`）
- 界面风格：浅色政务风，顶部统计卡片 + 趋势图表 + 业务明细表格

## 环境要求

Node 16+（本项目在 Node v16.14.2 下验证，因此锁定 Vite 4，不兼容 Vite 5+）。

## 安装与运行

```bash
npm install --registry=https://registry.npmmirror.com

# 开发模式（默认 5173 端口）
npm run dev

# 生产构建，产物在 dist/
npm run build

# 静态服务预览构建产物（示例：5192 端口）
python -m http.server 5192 --directory dist
```

后端地址在 `src/api/base.ts` 中通过 `API_BASE` 配置，如后端不在本机 8003 端口需同步修改后重新构建。

## 功能页面

| 页签 | 对应功能 | 主要能力 |
| --- | --- | --- |
| 状态实时监测 | 功能 1 | 近 7 日告警趋势（按等级堆叠）、告警等级/类型分布；井盖倾角、位移、破损、井下水位、有毒气体多维实时表（超阈值高亮、仅看异常开关）；手工采集监测数据并自动研判产生告警；单井多指标历史曲线；风险告警清单多条件查询 |
| 一井一档数字档案 | 功能 2 | 区域/状态/权属单位统计图；台账多条件组合查询（关键字、区域、类型、状态、权属单位）+ 分页；新增建档（自动生成 `JG-YYYY-NNN` 编号）与编辑；档案详情抽屉（基础信息、权属、最新监测、防坠网、维修更换历史、近期告警）；维修/更换履历登记 |
| 隐患闭环处置 | 功能 3 | 工单状态分布与闭环率、平均闭环时长；工单列表按状态呈现「派发 → 处置上报 → 整改核验 → 闭环销号」操作；核验不通过自动退回处置中；处置流程时间线抽屉 |
| 被盗追踪管理 | 功能 4 | 被盗异动案件列表（含轨迹点数、公安案件号与办案进展）；轨迹回放（经纬度折线 + 逐点播放/进度条/明细表）；最新位置定位追踪；异动轨迹点上报；公安联动报案（自动生成案件编号）与办案进展更新，追回后井盖转入维修中 |
| 防坠网台账 | 功能 5 | 状态分布与安装覆盖率、破损待修、超期未检查统计；台账多条件查询；安装登记（自动生成 `FZ-YYYY-NNN`）；破损登记/维修/更换运维记录；单网运维台账抽屉 |

任一页签发生数据写入后会回调刷新顶部统计卡片，保持大屏数据一致。

## 目录结构

```
src/
├─ api/            # axios 实例与全量接口封装
├─ components/     # StatCards + 五个功能面板
├─ styles/main.css # 政务浅色主题样式
├─ types/          # 与后端一致的数据模型定义
├─ utils/          # 标签配色、数值/时间格式化、ECharts 配置工厂
├─ App.vue
└─ main.ts
```

## 说明

- 演示数据由后端 `seed.py` 确定性生成（12 座井盖、监测/告警/工单/轨迹/公安/防坠网全链路样本），前端不含任何 mock。
- 表格中的红色/橙色高亮阈值与后端一致：倾角 15°、位移 10mm（被盗异动 30mm）、水位 80cm、有毒气体 10ppm。
